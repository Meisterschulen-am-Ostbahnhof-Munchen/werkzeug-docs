# Miniware SA80

Link: https://e-design.com.cn/en/MHP50-Mini-Soldering-Station-Adapter-PG10435436

Lötspitzen: **TS80P-Spitzen** (Weller-ähnlich)

Adapter, der aus einer **MHP50 Heizplatte** einen Lötkolben macht, der mit TS80P-Spitzen umgehen kann. Kein Extra-Griff notwendig.
