Intelligent, stationary soldering station with separate base unit.

| Feature | Description |
|---------|-------------|
| **Type** | Stationary, intelligent soldering station (with separate base unit). |

| **Compatibility** | Compatible with various soldering handles (e.g., F245 and F210). |
| **Operation** | Multiple preset temperature settings and adjustable modes. |

| **Target Audience** | Primarily for professional use or demanding hobbyists. |
