# FNIRSI HS-01
Soldering Tips: Special, **proprietary tips** (not JBC compatible!)

- Link: https://www.fnirsi.com/de/products/hs-01
- Wiki: https://docs.ms-muc-docs.de/projects/werkzeug-docs/de/latest/elektronik/loeten/heisses_werkzeug/loetkolben/fnirsi/HS-01.html
**Special Feature:** Aluminum cap – the soldering iron can be placed in a tool bag even when hot.
Previous to the HS-02. Smart, portable soldering iron.

| Feature | Description |
|---------|-------------|
| **Type** | Smart, portable soldering iron. |
| **Power** | Up to 65W (USB-C PD). |
| **Power Supply** | USB-C (PD-enabled). |
| **Temperature Range** | Approx. 80–420°C. |
| **Display** | OLED display (slightly smaller than the HS-02). |
**Speed** | Fast heat-up (approx. 8 seconds to melt tin at 65W). |
**Features** | Compact and lightweight, integrated PID control system for precise temperature control. |
