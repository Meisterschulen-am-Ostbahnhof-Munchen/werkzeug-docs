# Miniware SA80

Link: https://e-design.com.cn/en/MHP50-Mini-Soldering-Station-Adapter-PG10435436
Soldering tips: **TS80P tips** (Weller-like)
Adapter that turns an **MHP50 hot plate** into a soldering iron compatible with TS80P tips. No extra handle required.
