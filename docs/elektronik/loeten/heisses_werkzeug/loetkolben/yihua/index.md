# Yihua

alle Modelle: **JBC Spitzen**

Link: http://yihua-soldering.com/

Die Firma **Yihua** (Guangzhou Yihua Electronic Equipment Co., Ltd.) ist ein chinesisches Unternehmen, spezialisiert auf Lötausrüstung und DC-Netzteile. Bekannt als Lieferant von:

- Heißluft-Lötstationen
- 2-in-1 oder 3-in-1 Löt- und Rework-Stationen (SMD-Komponenten, BGA-Reparaturen)
- Lötkolben
- Gleichstromversorgungen

Bedient sowohl Hobbyelektroniker als auch professionelle Werkstätten weltweit.
